# Закрытые материалы

Содержимое этого каталога в git не попадает (`.gitignore`): файлы нельзя
распространять в публичном репозитории. Из облачной сессии они не скачались:
сайты с ними закрыты сетевой политикой. Собираются на макбуке.

| Что | Куда положить | Откуда взять |
|---|---|---|
| Штатный драйвер ATI с ноутбуков | `ati-installed/z505le/`, `ati-installed/c1vpk/` | агент скопирует с самих ноутбуков: файлы драйвера из `C:\WINDOWS\SYSTEM`, его INF из `C:\WINDOWS\INF`, ветку реестра адаптера |
| Установочный пакет драйвера Sony/ATI | `ati-installer/` | диски восстановления Sony или архивы драйверов VAIO |
| Windows 98 DDK | `ddk98/` | образ DDK; нужны примеры драйверов дисплея и mini-VDD |
| DirectX 7 DDK | `dx7ddk/` | пример HAL Direct3D для Permedia и заголовки DDI |
| DirectX 8.1 SDK | `dx81sdk/` | тесты D3D и отладочная версия DirectX |
| Документация ATI по регистрам Rage Pro | `ati-docs/` | руководство программиста Rage Pro, если найдётся |

Штатный драйвер нужен для замеров и сравнения поведения (какие возможности
объявляет, какой уровень DDI), а не как источник кода.
